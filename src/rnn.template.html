    Gradient check: does BPTT agree with a numerical derivative?

    How does the error signal change as it travels back in time?

    Length of the error vector at each time step. If it shrinks towards earlier steps the gradient is vanishing; if it grows it is exploding. Try a sigmoid hidden layer with small recurrent weights in the Custom tab.

    How much does each input influence the loss?

    Length of $\partial L/\partial x_t$ for every input. This is the idea of the “connectivity” plot used to compare memory in RNNs: an input far in the past with a tiny bar is hardly used. Accuracy alone cannot show this, two models can have the same accuracy and look back very differently.
